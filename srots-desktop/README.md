# SROTS Desktop

SROTS (SORTS Resource & Operations Control System) Enterprise Control Plane Native Desktop Application.

## Technology Stack
- **Language**: Java 21 LTS
- **UI Framework**: JavaFX 21
- **Layout & Style**: FXML + JavaFX CSS (`base.css`, `theme.css`)
- **Build System**: Maven
- **Architecture**: MVVM + Clean Architecture

## Running the Application

```powershell
mvn clean compile javafx:run
```
